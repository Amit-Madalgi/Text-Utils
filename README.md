# TextUtils 📝

**TextUtils** is a React-based text utility web application that allows users to analyze and manipulate text quickly and easily. It provides useful features like counting words and characters, converting text to uppercase/lowercase, removing extra spaces, and toggling between light and dark mode for better accessibility.

## 🔗 Live Demo
https://amit-madalgi.github.io/Text-Utils/
---

## 🚀 Features

- 🔤 Convert text to **Uppercase / Lowercase**
- 📏 Count **Words** and **Characters**
- ✂️ **Remove Extra Spaces**
- 🌙 Toggle between **Light** and **Dark Mode**
- ⚡ Instant updates with smooth UI
